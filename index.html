Android Duty Mode

LOCK46 turns a personal Android phone into an essentials-only device for exactly as long as you are on duty. You start the period, you choose the length, and you decide which apps stay available. Everything you have not approved is blocked the moment you try to open it.

When the timer runs out, the phone returns to normal on its own. Ending duty early requires an admin PIN.

Duty periods

Start duty with a preset — 30 minutes, 1, 2, 4 or 8 hours — or set a custom length up to 24 hours. The remaining time and the exact end time are always on screen.

Default is block

Nothing is allowed because of what category it belongs to. You approve specific apps; everything else is unavailable until duty ends. The home screen, keyboard and dialer stay available automatically.

Real enforcement

Blocking happens when you actually open a restricted app, not just inside a launcher screen. A LOCK46 screen appears over the app with the time remaining and a way back to the home screen.

Emergency calling

The dialer is never intentionally blocked, whether or not you have added it to your essential apps. LOCK46 does not intercept, record or read call content.

Survives a reboot

Restarting the phone does not clear an active duty period. State is restored on boot, including before the first unlock, and the timer picks up where it left off.

Offline by construction

No account, no server, no cloud, no analytics. The app does not declare the internet permission at all, so it cannot phone home even if something tried to.

What LOCK46 stores

Only what the restriction needs to work, all of it on the device: your approved app list, the current duty period's start and end time, your duty-duration default, and a salted PBKDF2 hash of your admin PIN. The PIN itself is never stored and never written to logs.

It does not collect calls, messages, contacts, location, microphone, camera, files or browsing history. The accessibility service reads only the package name of the app coming to the foreground — never screen content.

What V1 is not

LOCK46 V1 is a normal installed Android app, not a managed-device deployment. Android does not give a sideloaded APK unlimited control over a personal phone, and this release does not pretend otherwise.

Someone with physical access to an unlocked phone can disable the accessibility service, boot into safe mode, or uninstall LOCK46. The admin PIN is a prototype authorisation mechanism that stops casual early exit — it is not tamper resistance. Device Owner / Android Enterprise enforcement is planned for V2.

Getting started

  1. Download LOCK46-v1.apk and open it. Allow installation from this source if Android asks.
  2. Open LOCK46 and follow the five setup steps.
  3. Create an admin PIN — this is the only way to end duty early.
  4. Grant the accessibility service and display-over-other-apps permissions. Each is explained before you are sent to Android settings.
  5. Choose your essential apps.
  6. Press START DUTY when you report for duty.
